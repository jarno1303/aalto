# Aalto

Aalto on nopean ja pelkistetyn radio-sovelluksen ensimmäinen Android-prototyyppi.

Tässä vaiheessa mukana on:

- premium-henkinen aloitusnäkymä
- radioasemien valinta
- suosikki-tila
- Media3/ExoPlayer-pohjainen oikea radio-streamien toisto
- puhelimelle sopiva responsiivinen käyttöliittymärunko
- valmius myöhempään autotilaan, katalogiin ja taustatoiston viimeistelyyn

Ensimmäiset Ylen, Radio Helsingin ja Nelonen Median HLS-radio-streamit on kytketty. Bauer/Radioplay-kanavat jätettiin pois prototyypistä, koska ne palauttivat kolmannen osapuolen soittimessa tukilopetusilmoituksen varsinaisen lähetyksen sijaan. Seuraava vaihe on laitetestaus, virhetilojen käsittely ja kuratoidun asemakatalogin laajennus.
